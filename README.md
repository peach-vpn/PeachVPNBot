# 🍑 Персик VPN

Telegram-бот бесплатного VPN.

## Возможности

- 🆓 Бесплатная подписка
- ♾️ Безлимитный трафик
- 📅 Подписка на 7 дней
- 🔄 Обновление подписки
- 🎟 Промокоды
- 👥 Админ-панель
- 🌍 VLESS Reality
- 🇳🇱 Нидерланды
- 🇩🇪 Германия
- 🇰🇿 Казахстан

## Структура

- `bot.py` — Telegram-бот
- `config.py` — настройки
- `database.py` — база пользователей
- `github_api.py` — работа с GitHub
- `nodes.txt` — VPN-ноды
- `requirements.txt` — зависимости

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
